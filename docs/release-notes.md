e-server desktop client for Windows 10+ (x64), Ubuntu, Arch Linux and Linux AppImage (x86_64).

Install the client, connect to your private network or VPN, and enter your e-server HTTPS address. Your server verifies its PIN and your Easter Company account. No server credentials are bundled into these installers.

Includes a protected Electron renderer, system-browser sign-in, file uploads/downloads, camera/microphone/screen-sharing permission prompts, notifications, tray support and verified per-user updates. Patch updates preserve state; minor updates clear HTTP cache; major updates clear the server's local sign-in state. Updates stage in the background and wait for an idle, unfocused client. Save active work before manually restarting for an update.

Windows installers are currently unsigned. SmartScreen may warn; verify the source repository and SHA256SUMS before running. Linux AppImage may require FUSE 2. macOS, ARM and mobile clients are not offered.
