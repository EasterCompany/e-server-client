e-server desktop client for Windows 10+ (x64), Ubuntu, Arch Linux and Linux AppImage (x86_64). Install the client, connect to your private network or VPN, and enter your e-server HTTPS address. No server credentials are bundled into these installers.

This release prepares the client for an internal rename, and it is the build that makes that rename safe on the machine you already have: it keeps reading and applying its own updates while the new name starts to appear. Install it once and the next release arrives on its own — there is nothing to do after this one.

Nothing you use day to day changes. One Easter Company sign-in, the account in your server's top navigation, the sign-out that ends both, and the way the client updates all behave exactly as they did in 1.0.2.

Windows installers are currently unsigned. SmartScreen may warn; verify the source repository and SHA256SUMS before running. Linux AppImage may require FUSE 2. macOS, ARM and mobile clients are not offered.
