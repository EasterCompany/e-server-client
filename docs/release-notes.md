e-server desktop client for Windows 10+ (x64), Ubuntu, Arch Linux and Linux AppImage (x86_64). Install the client, connect to your private network or VPN, and enter your e-server HTTPS address. No server credentials are bundled into these installers.

The client's internal package name is now easter-server-client, matching the repository these downloads come from.

The sign-in is Easter Company's own account page now, the same one the website and the launcher use: the same provider buttons in the same order, the same username and password form, the same words, in e-server's colours with the Easter Company mark beside the e-server wordmark. It signs you in to your Easter Company account and nothing else; a server still asks for its own access separately. The server address screen is unchanged, and an update that cannot be checked no longer stands between you and the sign-in page.

If you are already on 1.0.3, this release arrives on its own. If you are on 1.0.2 or older and did not install 1.0.3, install this one by hand once — builds older than 1.0.3 cannot read the renamed update package, so they will not update themselves. After that, updates are automatic again.

Windows installers are currently unsigned. SmartScreen may warn; verify the source repository and SHA256SUMS before running. Linux AppImage may require FUSE 2. macOS, ARM and mobile clients are not offered.
